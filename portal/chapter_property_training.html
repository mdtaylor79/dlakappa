Chapter Property Accountability Training

A 30-minute interactive course covering the Chapter Property Accountability Manual & Operational Policy (POL-PROP-2026-01) — asset classification, security architecture, custody procedures, and financial accountability.

4 Modules + Final Assessment ~30 Minutes Certificate Awarded 80% to Pass
Course Learning Objectives
  • Identify ownership categories and interpret the Property Control Number (PCN) system
  • Classify assets using the four-tier security architecture and Security Classification Matrix
  • Apply the physical security requirements for each protection level
  • Execute check-out and return procedures in compliance with chapter policy
  • Distinguish financial accountability thresholds that require officer approval
  • Describe damage reporting, audit, and annual review requirements
  • Explain custody transfer and emergency disposition procedures
